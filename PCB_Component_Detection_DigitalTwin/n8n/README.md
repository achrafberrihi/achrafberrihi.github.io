# n8n workflows

| File | Webhook | What it does |
|---|---|---|
| `pcb_inspection_workflow.json` | `POST /webhook/pcb-inspect` | Roboflow YOLO inference → circuit analysis (Code node) → LLM explanation → JSON with analysis, explanation and digital-twin payload |
| `pcb_chatbot_workflow.json` | `POST /webhook/pcb-chat` | Follow-up questions about an analyzed board, with conversation history |

```
Webhook ─► Roboflow YOLO inference ─► Analyze circuit (JS) ─► LLM explanation ─► Build response ─► Respond
```

## Import and configure

1. In n8n: **Workflows → Import from file** and pick each JSON.
2. Set these environment variables on the n8n instance (or replace the `$env` expressions with credentials):

| Variable | Example |
|---|---|
| `ROBOFLOW_API_KEY` | your private API key |
| `ROBOFLOW_MODEL` | `pcb-components` |
| `ROBOFLOW_VERSION` | `3` |
| `ROBOFLOW_API_URL` | optional, defaults to `https://detect.roboflow.com` |
| `ANTHROPIC_API_KEY` | key for the explanation / chatbot model |
| `LLM_MODEL` | optional, defaults to `claude-haiku-5-5` |

   Recent n8n versions block `$env` in nodes by default: set `N8N_BLOCK_ENV_ACCESS_IN_NODE=false`, or store the keys as n8n credentials (Header Auth / Query Auth) instead.
3. Activate the workflows.

## Call them

```bash
curl -X POST https://<your-n8n>/webhook/pcb-inspect \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/board.jpg", "board_width_mm": 80,
       "expected_bom": {"resistor": 4, "capacitor": 6}}'

curl -X POST https://<your-n8n>/webhook/pcb-chat \
  -H "Content-Type: application/json" \
  -d '{"analysis": { ...from pcb-inspect... }, "question": "How can I reduce power consumption?", "history": []}'
```

The `Analyze circuit` Code node is a JavaScript port of `pcb_inspector/analysis.py` and `twin.py`. The test suite runs it with Node.js on the sample detections and checks it gives the same result as the Python version.

The JSON files are generated by `tools/build_n8n_workflows.py`, so edit that script (not the JSON) and re-run it.
